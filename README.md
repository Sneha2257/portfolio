# Kumari Sneha — Presentation Specialist & Executive Deck Designer Portfolio

A premium animated presentation design portfolio showcasing high-stakes investor pitch decks, enterprise transformation roadmaps, data visualization (Thinkcell), and Middle East Arabic RTL layouts.

## Visual Centerpiece: Work / Selected Projects Section

Inspired by high-end presentation decks, Apple-style product showcases, and modern creative agencies:

1. **Section Entrance Animation**:
   - Scroll-triggered entrance with staggered reveal (Eyebrow &rarr; Title &rarr; Subtitle &rarr; Category Filters &rarr; Cards).
   - Smooth Apple-style cubic easing (`cubic-bezier(0.16, 1, 0.3, 1)`).

2. **Featured Project Showcase (Large Horizontal Card)**:
   - Interactive 3D mouse parallax cursor tilt.
   - 16:9 presentation mockup with live slide cycler tabs (`Vision`, `Value Chain`, `Roadmap`).
   - Flagship deck: *AI Transformation Roadmap for Finance*.

3. **Horizontal Project Showcase**:
   - Smooth horizontal drag/scroll track with arrow buttons.
   - Dynamic card scaling based on position (Center active card is 1.04x, adjacent cards 0.94x with partial visibility).
   - Real-time progress indicator: `01 ━━━━━━━ 04`.

4. **Project Cards Grid**:
   - Large 16:9 deck preview frames with subtle slide badges.
   - On hover: 1.04x smooth scale, upward card lift (-8px), deep ambient shadow, transparent overlay fade, and sliding "View Project &rarr;" action.

5. **Before &rarr; After Presentation Makeover Slider**:
   - Draggable split-screen comparison slider with minimal animated handle.
   - Compares raw, unformatted 12-bullet client draft against Sneha's executive 3-pillar data-viz redesign with Thinkcell KPI scorecards.
   - Interactive touch, mouse drag, and keyboard arrow controls.

6. **Case Study Opening & Cinematic Presentation Slide Viewer**:
   - Smooth shared-element expansion from card into fullscreen case study view.
   - 16:9 presentation cinema stage with slide-by-slide navigation (`01 / 03`), slide thumbnail tray, and subtle zoom/pan movement on key data points.
   - In-depth 4-act story breakdown: The Strategic Mandate, The Bottleneck, Sneha's Solution, and Measurable Outcomes.

## How to Run

- **Direct Browser**: Double-click `launch.bat` or open `index.html` in any browser (Chrome, Edge, Safari, Firefox).
- **Local Server (Optional)**:
  ```bash
  npx serve .
  # or
  python -m http.server 3000
  ```
